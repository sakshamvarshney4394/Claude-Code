# Institution Information

This file is intended to store information about the institution associated with this project.
It will be read by Claude Code in future sessions to maintain context about the institution.

## Details to Include:
- Institution Name
- Mission/Goals
- Relevant Departments or Teams
- Key Contacts
- Any other institutional context that should persist across sessions

## Example:
```
# Institution: Sample Tracking Institute
# Mission: To advance sample tracking technologies for research and industry.
# Department: Research and Development
# Contact: Dr. Jane Doe (j.doe@institute.edu)
```

*Note: This file is automatically read by Claude Code at the start of each session if it exists in the project root.*
